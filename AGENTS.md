# Janiguda Agent Guide

## Project goal

Build an original, stylized 3D open-world prototype based on the area around
`18.690209, 82.834109` in Janiguda/Jharaput, Koraput, Odisha. It targets macOS
and Windows first, browser export where practical, and mobile later.

Use the supplied real-world photographs as visual reference for layout,
colours, vegetation, roads, shops, houses and landmarks. Do not copy protected
game assets or Google imagery into the shipped game.

## Engine and scale

- Godot 4.7.1; compatibility renderer.
- Main project file: `project.godot`.
- Main scene: `main.tscn`.
- One Godot unit represents approximately one metre.
- World origin `(0, 0, 0)` represents `18.690209, 82.834109`.
- Local X/Z are horizontal map coordinates; Y is elevation.

## Architecture

- `scripts/main.gd`: builds the environment, gameplay objects, player, UI,
  bicycle and NPCs.
- `scripts/geographic_world.gd`: generates the 2 km x 2 km terrain, mapped
  roads, vegetation, buildings and detailed spawn area.
- `scripts/player.gd`: third-person movement, animation, inventory and player
  interactions.
- `scripts/bicycle.gd`: bicycle mounting and driving.
- `scripts/npc.gd`: NPC conversation and hit reactions.
- `scripts/shop.gd`: cigarette shop interaction.
- `data/location_osm.json`: cached OpenStreetMap geometry.
- `data/elevation_grid.json`: cached SRTM elevation samples.
- `JaniGudaGate.tscn`: large editor-saved copy of the generated map for manual
  visual editing. Treat it as user-authored work.

The normal runtime map is generated by `geographic_world.generate()`. An
editor-saved map can coexist only if runtime generation is disabled; otherwise
the geometry will appear twice.

## Current working-tree warning

Before editing, always run `git status --short`. The user may have unsaved or
uncommitted Godot editor work. In particular, changes to `main.tscn`,
`scripts/player.gd` and `JaniGudaGate.tscn` may belong to the user. Never reset,
replace, regenerate or discard them without explicit permission. Make narrow
patches and preserve unrelated changes.

## Editing guidance

- Prefer reusable `.tscn` scenes for manually placed buildings, vegetation and
  props.
- Keep important areas hand-built; use procedural generation or MultiMesh for
  distant/repeated vegetation.
- Use simple primitive colliders for buildings, walls, trees and props.
- Place objects on terrain with
  `geographic_world.surface_height_at(x, z)` when editing code.
- Use `geographic_world.nearest_primary_frame(position)` to align objects with
  Nandapur Road.
- Keep browser performance in mind: low-poly meshes, shared materials, limited
  shadows and no collision on decorative objects.
- Do not hand-edit huge serialized mesh byte arrays inside
  `JaniGudaGate.tscn`. Use Godot's 3D editor for that scene.

For gameplay changes, run the project for at least several seconds and test the
affected interaction. For visual work, render or play-test from the third-person
camera and verify that the player/bicycle do not float or enter the terrain.

## Controls

- WASD: move or drive
- Shift: run or bicycle boost
- Space: jump
- Mouse: camera
- E: interact, mount or dismount
- F: smoke
- I: inventory

Confirm controls against the current scripts before documenting new behavior;
the user may be actively changing gameplay.
